# Repository instructions

## Commit and pull request attribution

- Never add Claude or Anthropic as a commit author or co-author.
- Never append Claude-generated bylines, promotional footers, or Claude session links to commit messages or pull request descriptions.
- Preserve the human author's identity and required `Signed-off-by` trailer.
- Keep `.claude/settings.json` attribution disabled. Do not override it in local settings or command-line options.
- Install the repository hooks with `scripts/install-git-hooks.sh`. Keep them enabled; do not bypass attribution checks.
